# DocuFlow — استوديو إنتاج الفيديو الوثائقي

لوحة عربية RTL مبنية بـFastAPI لإنتاج فيديوهات وثائقية عربية أو إنجليزية، أفقية 16:9 أو عمودية 9:16. يختار المستخدم مدة 1 أو 3 أو 5 أو 10 دقائق. يطلب المحرك من موفر النص سيناريو قصيراً لكل مشهد، ويبحث عن لقطات Pixabay متحركة غير مكررة. عند تعذر الفيديو ينتقل إلى صورة Pollinations بعد موافقة صريحة ومفتاح، ثم صورة Pixabay متحركة، ثم خلفية محلية عليها حركة Ken Burns. يطبع التطبيق كل ملف فيديو مصدر عبر `-map 0:v:0 -an -sn -dn` مع حذف metadata وtimecode، حتى لا تتسرب مسارات `tmcd` إلى ملفات المشاهد.

تتغير اللقطات كل 3.78 ثانية تقريباً، مدة أي ملف مشهد مصدري لا تتجاوز 4 ثوانٍ، ويعبر الانتقال بينها بتداخل `crossfade` قدره 0.22 ثانية. ينتج ذلك مدداً قريبة من المحدد: نحو 1:01 و3:02 و5:03 و10:01؛ يتوقف طول الفيلم الفعلي على عدد المشاهد ومعدل الإطارات. يظل فيديو كل مشهد متحركاً بالكاميرا الافتراضية حتى عند غياب اللقطات الخارجية.

## التشغيل السريع

**Windows:** ثبّت Python 3.11 أو أحدث وFFmpeg مع دعم `subtitles/libass`، وأضف `ffmpeg` إلى PATH. شغّل `start.bat`؛ ينشئ بيئة Python ويثبت المتطلبات عند أول تشغيل ثم يفتح `http://127.0.0.1:3000`.

**Linux:** ثبّت Python 3.11 أو أحدث وFFmpeg وlibass والخط العربي، مثلاً في Ubuntu/Debian: `sudo apt-get install ffmpeg libass9 fonts-noto-core python3-venv`. امنح `start.sh` صلاحية التنفيذ عند الحاجة (`chmod +x start.sh`) ثم شغّله.

تحتاج edge-tts إلى الإنترنت؛ أول تشغيل لـfaster-whisper ينزّل نموذج التفريغ. معالجة 10 دقائق/159 مشهداً تتطلب وقت CPU ومساحة أكبر بكثير من فيديو الدقيقة؛ وضع التجربة المحلي يدعم الدقيقة الواحدة فقط. للمدد 3/5/10 دقائق اختر مزود كتابة مثل Gemini أو Groq أو Pollinations وأضف مفتاحه.

## الاستخدام ومحدد المدة

1. أدخل موضوعاً واحداً أو قائمة موضوعات (موضوع لكل سطر، حتى 8 موضوعات في الدفعة)، وحدد اللغة والصوت والنسبة والمدة. تقابل اختيارات 1/3/5/10 دقائق تقريباً 16/48/80/159 مشهداً.
2. يطلب السيناريو خطافاً في البداية، وتصاعداً وكشفاً وخاتمة. المشهد قصير، وفيديوهاته لا تتجاوز 4 ثوانٍ؛ وتكون استعلامات المرئيات الإنجليزية محددة للمشهد، مثل `cargo ship storm Atlantic night` و`vintage airplane flying clouds archival` و`compass navigation map closeup`، لا كلمات عامة مثل `fog` أو `ocean`. يُطلب من النموذج تفادي اختلاق أرقام ومصادر، وتمييز الحقيقة المنقولة عن الفرضية. عند العربية يُكتب السرد بالعربية الفصحى وتُختار أصوات مثل `ar-EG-ShakirNeural` أو `ar-SA-HamedNeural`.
3. **Gemini:** يقرأ التطبيق `models.list` لحسابك ويختار معرف `generateContent` الذي يظهر في القائمة الحية، ثم يجرب النماذج النشطة التالية عند أخطاء 404 أو عدم التوفر. لا يفترض اسماً ثابتاً قديماً. وتبقى الحصة الفعلية حسب حساب Google ومفتاحه.
4. **النص:** تتوفر Groq وGemini والوضع التجريبي، إضافة إلى خيار Pollinations. وضع التجربة بلا موفر نص خارجي ويعطي فيديو اختبار مدته دقيقة؛ لا يمثل كتابة وثائقية مخصصة من نموذج لغوي ولا يدعم المدد الأطول. Pollinations ليس keyless: يتطلب مفتاحاً وقد يستهلك رصيد Pollen.
5. **المقاطع:** أدخل Pixabay API Key لجلب فيديوهات HD. داخل الفيديو الواحد تُحجز معرّفات Pixabay التي استُخدمت كي لا يعيد البحث اختيار clip ID نفسه؛ عند نفاد النتائج الفريدة يُستعمل مسار صور/خلفيات احتياطي بدلاً من تكرار الفيديو. لا تُشارك مفاتيحك.
6. **Pollinations للصور:** موافقة منفصلة مطلوبة لكل تشغيل. قد يطلب فيلم 10 دقائق توليد ما يصل إلى 159 صورة، وقد تصل دفعة من 8 موضوعات إلى 1,272 صورة إذا كانت جميع المشاهد بحاجة إلى الصور. راجع الأسعار والرصيد قبل الموافقة. بلا موافقة/مفتاح لا يرسل DocuFlow طلب توليد صور Pollinations.
7. تابع التقدم، ثم عاين MP4 ونزّله. تُحفظ المخرجات في `data/outputs/` على الجهاز.

## إيقاع الفيديو والمرئيات

يطبق FFmpeg حركة كاميرا 24fps (zoom-in / zoom-out وتحريك أفقي أو رأسي) على فيديو Pixabay والصور والخلفيات المحلية. يركب MoviePy انتقالات `crossfade` زمنها 0.22 ثانية بين المشاهد مع إبقاء زمن ظهور ملف المشهد عند أو دون 4 ثوانٍ. في أول 10 ثوانٍ تتبدل المشاهد بفواصل تقارب 3.78 ثانية. عند توفر مفتاح Pixabay ومقاطع مناسبة، يستخدم كل مشهد نتيجة مختلفة؛ لا يمكن ضمان وجود لقطة مناسبة لكل استعلام في مكتبة المخزون.

`8K-style` إن ظهر في الوصف يعني أسلوب/تفاصيل، لا إخراجاً فعلياً بدقة 8K. دقة الخرج HD: `1280×720` أو `720×1280`.

## الصوت والترجمة

يولد edge-tts مقطعاً مستقلاً لكل جملة. إذا تجاوز الصوت 3.78 ثانية يعاد التوليد بسرعة أعلى تدريجياً للحفاظ على الجملة كاملة؛ إذا لم تتسع الجملة ضمن الفاصل، يتوقف الإنتاج برسالة تطلب نصاً أقصر بدلاً من قص كلمة أو تمديد لقطة.

يستخرج faster-whisper توقيت الكلمات، ثم تقسم الترجمة العربية إلى شاشات من 3–5 كلمات بحروف ASS مشكّلة RTL. في السرد العربي، يساعد تفريغ العربية على محاذاة الجمل مباشرة. أما عندما يكون الراوي إنجليزياً والترجمة عربية، فتوزع مجموعات الكلمات العربية على الطابع الزمني للكلمات المنطوقة بنسبة الكلمات؛ هذه محاذاة مقطعية تقريبية وليست ترجمة كلمة-بكلمة أو ضماناً لتطابق دلالي تام. راجع النص والتزامن قبل النشر.

يولّد التطبيق موسيقى وثائقية محيطية محلياً ويخلطها تحت صوت الراوي، ثم يطبع المزيج بتمريرين عبر FFmpeg إلى هدف `−14 LUFS` و`−1.0 dBTP` مع limiter. القياس النهائي قد يتأثر بترميز AAC ومحتوى الصوت؛ استمع للملف النهائي قبل النشر.

## المفاتيح والخصوصية والتكلفة

مفاتيح Groq وGemini وPixabay وPollinations تُحفظ في `localStorage` لهذا المتصفح وتُرسل إلى الخلفية عند بدء التوليد، ولا تُكتب في ZIP. Pollinations قد يستهلك رصيد Pollen، لذا لا يُستخدم لتوليد الصور إلا بعد إدخال المفتاح وتفعيل الموافقة. راجع أسعار وحدود كل مزود قبل تشغيل مهام طويلة. لا يتضمن ZIP مفاتيح API أو ملفات الفيديو التجريبية.

## التشغيل اليدوي

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
HOST=127.0.0.1 PORT=3000 python -m app.main
```

على Windows فعّل `.venv\\Scripts\\activate` ثم شغّل `python -m app.main`. يتطلب التشغيل Python 3.11+ وFFmpeg حديثاً بدعم libass. يستخدم التطبيق افتراضياً نموذج faster-whisper `tiny` لتقليل الذاكرة والوقت.

## تشغيل محلي عبر Docker

ثبّت Docker Desktop أو Docker Engine مع Docker Compose، ثم من مجلد المشروع شغّل:

```bash
# Linux/macOS: مرّر UID/GID الحاليين كي تبقى الملفات المنشأة قابلة للكتابة من حسابك
APP_UID="$(id -u)" APP_GID="$(id -g)" docker-compose up -d --build
```

على Windows PowerShell أو Command Prompt (القيم الافتراضية 1000)، استخدم `docker-compose up -d --build`. يقبل Docker Compose v2 أيضاً الصيغة الحديثة `docker compose up -d --build`. افتح `http://localhost:3000`. عند احتلال المنفذ، غيّر منفذ المضيف مثلاً إلى `DOCUFLOW_PORT=3001` قبل التشغيل.

يحفظ الربط `./data:/app/data` الفيديوهات في `./data/outputs/` وملفات العمل في `./data/work/` على جهازك. يحفظ volume المسمى `docuflow_whisper_cache` نموذج faster-whisper بعد تنزيله لتجنب إعادة التنزيل. التطبيق يعمل بحساب غير root داخل الحاوية؛ يهيئ entrypoint مجلدات البيانات ثم يخفض الصلاحيات إلى UID/GID المحددين. لمزامنة الخدمة: `docker-compose logs -f`؛ للإيقاف: `docker-compose down` (لا يحذف البيانات). لا تستخدم `docker-compose down -v` إلا إذا أردت حذف كاش Whisper أيضاً.

# DocuFlow — لوحة إنتاج الفيديو الوثائقي

لوحة عربية RTL مبنية بـFastAPI لإنشاء فيديوهات وثائقية قصيرة وShorts: نص إنجليزي وخطاف وترجمة عربية، تعليق صوتي عبر edge-tts، لقطات فيديو اختيارية من Pixabay، توقيت عبر faster-whisper، وترجمات عربية ASS مدمجة في MP4.

## التشغيل السريع

**Windows:** ثبّت Python 3.11 أو أحدث وFFmpeg مع دعم مرشح `subtitles/libass` وأضف `ffmpeg` إلى PATH. انقر نقراً مزدوجاً على `start.bat`؛ ينشئ بيئة Python ويثبت المتطلبات عند أول تشغيل ثم يفتح `http://127.0.0.1:3000`.

**Linux:** ثبّت Python 3.11 أو أحدث وFFmpeg وlibass والخط العربي، على سبيل المثال في Ubuntu/Debian: `sudo apt-get install ffmpeg libass9 fonts-noto-core python3-venv`. امنح `start.sh` صلاحية التشغيل عند الحاجة (`chmod +x start.sh`) ثم شغّله. تُفتح اللوحة على `http://127.0.0.1:3000`.

يلزم الاتصال بالإنترنت لـedge-tts وطلبات مزودي الذكاء الاصطناعي وPixabay، ولتنزيل نموذج faster-whisper أول مرة. أول تشغيل قد يستغرق أطول من المعتاد بسبب تثبيت المكتبات وتحميل نموذج Whisper الصغير. تتطلب معالجة الوسائط CPU ومساحة قرص.

## الاستخدام

1. أدخل موضوعاً أو قائمة موضوعات، موضوعاً واحداً في كل سطر، حتى 8 موضوعات في الدفعة.
2. اختر YouTube 16:9 أو Shorts 9:16 وصوت الراوي الإنجليزي.
3. الوضع التجريبي يستخدم سيناريو جاهزاً وTTS فعلياً وخلفيات فنية محلية؛ لا يتصل بمزود نصوص أو بمكتبة فيديو. للاستخدام الكامل اختر Groq أو Gemini واحفظ المفتاح المناسب في صفحة الإعدادات. أضف مفتاح Pixabay اختيارياً لجلب المقاطع الفعلية؛ بدونه يستخدم التطبيق خلفيات محلية بديلة.
4. تابع المراحل ثم عاين MP4 ونزّله. يحفظ الأرشيف وبياناته داخل `data/outputs/` على جهازك.

## Pixabay Videos API

يستخدم جالب الفيديو نقطة النهاية الرسمية `https://pixabay.com/api/videos/` مع `key` و`q`. تُرسل عبارة البحث بحد أقصى 100 حرف، ثم تُقرأ النتائج من `hits[].videos`. يختار التطبيق ملفاً مناسباً لاتجاه الفيديو من الأبعاد المتاحة في `large` أو `medium` أو غيرهما، ويرفض الملفات التي تتجاوز 90 ميغابايت. راجع [توثيق Pixabay Developer API](https://pixabay.com/api/docs/) و[صفحة Pixabay الرسمية عن API](https://pixabay.com/service/about/api/) لمعلومات التسجيل وشروط الاستخدام الحالية.

## المفاتيح والخصوصية

مفاتيح Groq وGemini وPixabay تُخزَّن في `localStorage` لهذا المتصفح فقط، ولا تُحفظ في ملفات الخادم أو سجلاته؛ يرسلها المتصفح إلى الخدمة الخلفية عند بدء المهمة. مفتاح Pixabay يُستخدم في طلب HTTPS إلى API الرسمي ولا يُضمَّن في بيانات الفيديو أو ZIP. استخدم نسخة محلية على جهازك الشخصي، ولا تدخل مفاتيحاً شخصية في معاينة عامة أو متصفح مشترك. من الأفضل مسح المفاتيح عند الانتهاء على جهاز مشترك. احتفظ بمفاتيحك في مزودها ولا تضعها داخل ملفات المصدر أو ZIP.

تعتمد الخدمات الخارجية على سياساتها وحصصها ومفاتيحها؛ لا يعني وصف «مجاني» أن المزود يضمن حصة غير محدودة. لائحة Groq/Gemini وPixabay قابلة للتغيير؛ إذا غيّر المزود نقطة API أو قواعد الاستخدام، راجع توثيقه الحالي.

## الدقة والمخرجات

يُنشئ التطبيق ملف ASS عربي RTL؛ يستخدم FFmpeg/libass تشكيل النص واتجاهه، ويحدد faster-whisper أزمنة بداية ونهاية كل مشهد. الترجمة تجميع على مستوى المشهد، لا تفريغاً كلمةً بكلمة؛ يُستحسن مراجعة النص والتوقيت قبل النشر. يُنشأ مسار موسيقى خلفية توليدي خافت محلياً، وتستطيع إيقافه بتغيير خيار `background_music` في طلب API.

النسخة التجريبية تستخدم خلفيات تصميمية ثابتة محلياً كي تعمل دون مفتاح Pixabay، وليست لقطات أرشيفية حقيقية. يتطلب جلب اللقطات الفعلية مفتاح Pixabay صالحاً. المخرجات التجريبية لا تُعد تحققاً من دقة الحقائق أو من شروط مزود المحتوى الخارجي.

## بنية المشروع

`app/main.py` واجهة الخدمة والمهام والتنزيل؛ `app/pipeline.py` خط الإنتاج؛ `app/providers.py` موصلات النص وPixabay؛ `app/media.py` الصوت والمزامنة والتركيب؛ `app/templates` و`app/static` الواجهة. تُنشأ ملفات الفيديو في `data/outputs/` ومجلدات العمل المؤقتة في `data/work/`.

## التشغيل اليدوي

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
HOST=127.0.0.1 PORT=3000 python -m app.main
```

على Windows فعّل البيئة عبر `.venv\\Scripts\\activate` ثم استخدم `python -m app.main`. المتطلبات الأساسية تشمل Python 3.11+ وFFmpeg حديثاً مع libass. لتخفيض استهلاك الذاكرة غيّر `whisper_model` في جسم طلب `/api/generate` إلى `tiny` (الخيار الافتراضي)، أو اختبر `base` للحصول على تفريغ أفضل مقابل وقت أطول.

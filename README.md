# DocuFlow — استوديو إنتاج الفيديو الوثائقي

لوحة عربية RTL مبنية بـFastAPI لإنتاج فيديوهات وثائقية عربية أو إنجليزية، أفقية 16:9 أو عمودية 9:16. يختار المستخدم مدة 1 أو 3 أو 5 أو 10 دقائق. يطلب المحرك من موفر النص سيناريو قصيراً لكل مشهد ويبحث عن مرئيات مرتبطة به. تُطبّق حركة كاميرا سينمائية على الأصول المقبولة؛ وإذا لم يوجد أصل يجتاز شروط المطابقة والترخيص، يتوقف الإنتاج بدلاً من استخدام خلفية عامة لا صلة لها. يعتمد فحص الصلة على العنوان والوصف والوسوم والفئات، لا على تحليل بكسلات الصورة، ولذلك لا يمثل ضماناً دلالياً كاملاً.

تتغير اللقطات كل 3.78 ثانية تقريباً، ولا يتجاوز طول ملف المشهد المصدري 4 ثوانٍ، مع تداخل `crossfade` قدره 0.22 ثانية. ينتج ذلك مدداً قريبة من المحدد: نحو 1:01 و3:02 و5:03 و10:01؛ يتوقف طول الفيلم الفعلي على عدد المشاهد ومعدل الإطارات. يطبع التطبيق كل ملف فيديو مصدر عبر `-map 0:v:0 -an -sn -dn` مع حذف metadata وtimecode، حتى لا تتسرب مسارات `tmcd` إلى ملفات المشاهد.

## التشغيل السريع

**Windows:** ثبّت Python 3.11 أو أحدث وFFmpeg مع دعم `subtitles/libass`، وأضف `ffmpeg` إلى PATH. شغّل `start.bat`؛ ينشئ بيئة Python ويثبت المتطلبات عند أول تشغيل ثم يفتح `http://127.0.0.1:3000`.

**Linux:** ثبّت Python 3.11 أو أحدث وFFmpeg وlibass والخط العربي، مثلاً في Ubuntu/Debian: `sudo apt-get install ffmpeg libass9 fonts-noto-core python3-venv`. امنح `start.sh` صلاحية التنفيذ عند الحاجة (`chmod +x start.sh`) ثم شغّله.

تحتاج edge-tts إلى الإنترنت؛ أول تشغيل لـfaster-whisper ينزّل نموذج التفريغ. معالجة 10 دقائق/159 مشهداً تتطلب وقت CPU ومساحة أكبر بكثير من فيديو الدقيقة. وضع التجربة المحلي يوفّر سيناريو الجيزة لدقيقة واحدة فقط، لكن نجاح MP4 يتطلب العثور على مرئيات مطابقة لكل مشهد؛ إذا لم تتوفر يتوقف قبل التصيير. للمدد 3/5/10 دقائق اختر مزود كتابة مثل Gemini أو Groq وأضف مفتاحه.

## الاستخدام ومحدد المدة

1. أدخل موضوعاً واحداً أو قائمة موضوعات (موضوع لكل سطر، حتى 8 موضوعات في الدفعة)، وحدد اللغة والصوت والنسبة والمدة. تقابل اختيارات 1/3/5/10 دقائق تقريباً 16/48/80/159 مشهداً.
2. يطلب السيناريو خطافاً في البداية، وتصاعداً وخاتمة. المشهد قصير واستعلام المرئيات الإنجليزي محدد، مثل `cargo ship storm Atlantic night` أو `vintage airplane flying clouds archival` أو `compass navigation map closeup`، لا كلمات عامة مثل `fog` أو `ocean`. يُطلب من النموذج تفادي اختلاق أرقام ومصادر وتمييز الحقيقة المنقولة عن الفرضية. عند العربية يُكتب السرد بالعربية الفصحى وتُختار أصوات مثل `ar-EG-ShakirNeural` أو `ar-SA-HamedNeural`.
3. **Gemini:** يقرأ التطبيق `models.list` لحسابك ويختار معرف `generateContent` الذي يظهر في القائمة الحية، ثم يجرب النماذج النشطة التالية عند أخطاء 404 أو عدم التوفر. لا يفترض اسماً ثابتاً قديماً. وتبقى الحصة الفعلية حسب حساب Google ومفتاحه.
4. **النص:** تتوفر Groq وGemini والوضع التجريبي، إضافة إلى خيار Pollinations. وضع التجربة بلا موفر نص خارجي يقتصر على سيناريو الجيزة الموثق ومدته دقيقة؛ لا يمثل كتابة مخصصة من نموذج لغوي ولا يدعم المدد الأطول. لا يُستخدم السيناريو الجاهز لموضوعات المايا/الأزتك أو لأي موضوع أهرامات غير محدد بمصر/الجيزة. قد يتوقف إذا تعذر العثور على 16 أصلاً بصرياً مناسباً، لذلك لا يضمن إعداد العينة نجاح MP4. Pollinations يتطلب مفتاحاً وقد يستهلك رصيد Pollen.
5. **المقاطع والصور:** أدخل Pixabay API Key لجلب فيديوهات HD. داخل الفيلم تُحجز معرّفات Pixabay لمنع تكرار الأصل نفسه. تستخدم صور Wikimedia Commons فقط عند مطابقة مرساة الموضوع ومصطلحات المشهد بحسب العنوان والوصف والفئات، ومع ترخيص يسمح بإعادة الاستخدام: الملكية العامة أو CC0 أو CC BY أو CC BY-SA. تُستبعد تراخيص NC وND والتراخيص غير المعروفة. يتضمن الناتج ملف إسناد قابل للتنزيل يذكر اسم الملف، واسم المؤلف/الائتمان إن توفر، والترخيص، ورابط صفحة الملف. لا تُقبل CC BY أو CC BY-SA إن نقص المؤلف/الائتمان أو روابط المصدر والترخيص. إذا لم يتوفر أصل مطابق، يفشل الإنتاج برسالة واضحة ولا يكرر الفيديو أو يركّب خلفية عامة.
6. **Pollinations للصور:** يتطلب مفتاحاً وموافقة منفصلة لكل تشغيل، وقد يستهلك رصيد Pollen. قد يطلب فيلم 10 دقائق توليد ما يصل إلى 159 صورة، وقد تصل دفعة من 8 موضوعات إلى 1,272 صورة إذا احتاجت جميع المشاهد صوراً. بلا موافقة أو مفتاح لا يرسل DocuFlow طلب توليد صور Pollinations.
7. تابع التقدم، ثم عاين MP4 ونزّله إن اكتمل التوليد. تُحفظ المخرجات في `data/outputs/` على الجهاز.

## مطابقة المرئيات وإيقاع الفيديو

لكل مشهد مرساة موضوع ثابتة ومصطلحات وصفية مرتبطة بالجملة المنطوقة. تُرفض نتائج Pixabay التي لا تتطابق بياناتها الوصفية مع المرساة ومصطلحات المشهد، ويُمنع تكرار معرّفات الفيديو والصور خلال الفيلم. عند تعذر Pixabay، يبحث المحرك في Wikimedia Commons عن صورة ذات صلة وترخيص مقبول، ويسجل الإسناد. يمكن استخدام صورة Pollinations فقط عند إدخال المفتاح وتفعيل موافقة الاستهلاك. إذا فشلت هذه المصادر، يتوقف التوليد بدلاً من ملء الفيلم بلقطات طبيعة/مدينة عامة. مطابقة metadata مرشح صلة مفيد، لكنها ليست فحصاً بصرياً لمحتوى الصورة ولا تثبت أن البكسلات تعرض الحدث المذكور؛ راجع المشاهد قبل النشر.

يطبق FFmpeg حركة كاميرا 24fps (zoom-in / zoom-out وتحريك أفقي أو رأسي) على الفيديوهات والصور المقبولة. يركب MoviePy انتقالات `crossfade` زمنها 0.22 ثانية بين المشاهد مع إبقاء زمن المشهد عند أو دون 4 ثوانٍ. تتبدل المشاهد في أول 10 ثوانٍ بفواصل تقارب 3.78 ثانية. لا يمكن ضمان وجود لقطة مناسبة لكل استعلام في مكتبة المخزون.

`8K-style` إن ظهر في وصف صورة مولدة يعني أسلوب/تفاصيل، لا إخراجاً فعلياً بدقة 8K. دقة الخرج HD: `1280×720` أو `720×1280`.

## الصوت والترجمة

يولد edge-tts مقطعاً مستقلاً لكل جملة. إذا تجاوز الصوت 3.78 ثانية يعاد التوليد بسرعة أعلى تدريجياً للحفاظ على الجملة كاملة؛ إذا لم تتسع الجملة ضمن الفاصل، يتوقف الإنتاج برسالة تطلب نصاً أقصر بدلاً من قص كلمة أو تمديد لقطة.

يستخرج faster-whisper توقيت الكلمات، ثم تقسم الترجمة العربية إلى شاشات من 3–5 كلمات بحروف ASS مشكلة RTL. في السرد العربي يساعد التفريغ العربي على محاذاة الجمل مباشرة. أما عندما يكون الراوي إنجليزياً والترجمة عربية، فتوزع مجموعات الكلمات العربية على الطابع الزمني للكلمات المنطوقة بنسبة الكلمات؛ هذه محاذاة مقطعية تقريبية وليست ترجمة كلمة بكلمة أو ضماناً لتطابق دلالي تام. راجع النص والتزامن قبل النشر.

يولّد التطبيق موسيقى وثائقية محيطية محلياً ويخلطها تحت صوت الراوي، ثم يطبع المزيج بتمريرين عبر FFmpeg إلى هدف `−14 LUFS` و`−1.0 dBTP` مع limiter. القياس النهائي قد يتأثر بترميز AAC ومحتوى الصوت؛ استمع للملف النهائي قبل النشر.

## المفاتيح والخصوصية والتكلفة

مفاتيح Groq وGemini وPixabay وPollinations تحفظ في `localStorage` لهذا المتصفح وترسل إلى الخلفية عند بدء التوليد، ولا تُكتب في ZIP. Pollinations قد يستهلك رصيد Pollen، لذا لا يُستخدم لتوليد الصور إلا بعد إدخال المفتاح وتفعيل الموافقة. راجع أسعار وحدود كل مزود قبل تشغيل مهام طويلة. لا يتضمن ZIP مفاتيح API أو ملفات الفيديو التجريبية.

## التشغيل اليدوي

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
HOST=127.0.0.1 PORT=3000 python -m app.main
```

على Windows فعّل `.venv\\Scripts\\activate` ثم شغّل `python -m app.main`. يتطلب التشغيل Python 3.11+ وFFmpeg حديثاً بدعم libass. يستخدم التطبيق افتراضياً نموذج faster-whisper `tiny` لتقليل الذاكرة والوقت.

## تشغيل محلي عبر Docker

ثبّت Docker Desktop أو Docker Engine مع Docker Compose، ثم من مجلد المشروع شغّل:

```bash
# Linux/macOS: مرّر UID/GID الحاليين كي تبقى الملفات المنشأة قابلة للكتابة من حسابك
APP_UID="$(id -u)" APP_GID="$(id -g)" docker-compose up -d --build
```

على Windows PowerShell أو Command Prompt (القيم الافتراضية 1000)، استخدم `docker-compose up -d --build`. يقبل Docker Compose v2 أيضاً الصيغة الحديثة `docker compose up -d --build`. افتح `http://localhost:3000`. عند احتلال المنفذ، غيّر منفذ المضيف مثلاً إلى `DOCUFLOW_PORT=3001` قبل التشغيل.

يحفظ الربط `./data:/app/data` الفيديوهات في `./data/outputs/` وملفات العمل في `./data/work/` على جهازك. يحفظ volume المسمى `docuflow_whisper_cache` نموذج faster-whisper بعد تنزيله لتجنب إعادة التنزيل. التطبيق يعمل بحساب غير root داخل الحاوية؛ يهيئ entrypoint مجلدات البيانات ثم يخفض الصلاحيات إلى UID/GID المحددين. لمزامنة الخدمة: `docker-compose logs -f`؛ للإيقاف: `docker-compose down` (لا يحذف البيانات). لا تستخدم `docker-compose down -v` إلا إذا أردت حذف كاش Whisper أيضاً.

# DocuFlow — لوحة إنتاج الفيديو الوثائقي

لوحة عربية RTL مبنية بـFastAPI لإنتاج فيديوهات وثائقية قصيرة وShorts. اختر اللغة العربية أو الإنجليزية للنص والتعليق الصوتي، وحدد نسبة العرض، ثم أنشئ مقاطع فيديو عبر Pixabay، وتوقيتاً عبر faster-whisper، وترجمات عربية RTL بصيغة ASS مدمجة في MP4.

## التشغيل السريع

**Windows:** ثبّت Python 3.11 أو أحدث وFFmpeg مع دعم مرشح `subtitles/libass` وأضف `ffmpeg` إلى PATH. انقر نقراً مزدوجاً على `start.bat`؛ ينشئ بيئة Python ويثبت المتطلبات عند أول تشغيل ثم يفتح `http://127.0.0.1:3000`.

**Linux:** ثبّت Python 3.11 أو أحدث وFFmpeg وlibass والخط العربي، على سبيل المثال في Ubuntu/Debian: `sudo apt-get install ffmpeg libass9 fonts-noto-core python3-venv`. امنح `start.sh` صلاحية التشغيل عند الحاجة (`chmod +x start.sh`) ثم شغّله. تُفتح اللوحة على `http://127.0.0.1:3000`.

يلزم الاتصال بالإنترنت لـedge-tts وطلبات مزودي الذكاء الاصطناعي وPixabay، ولتنزيل نموذج faster-whisper أول مرة. أول تشغيل قد يستغرق أطول من المعتاد بسبب تثبيت المكتبات وتحميل نموذج Whisper الصغير. تتطلب معالجة الوسائط CPU ومساحة قرص.

## الاستخدام

1. أدخل موضوعاً أو قائمة موضوعات، موضوعاً واحداً في كل سطر، حتى 8 موضوعات في الدفعة.
2. اختر YouTube 16:9 أو Shorts 9:16، ثم اختر لغة الفيديو والصوت الذي يناسبها. اختيار العربية يغيّر النص والصوت إلى العربية، ويستخدم ترجمة عربية مطابقة للصوت؛ كلمات بحث Pixabay تبقى بالإنجليزية. تتضمن أصوات العربية `ar-EG-ShakirNeural` و`ar-SA-HamedNeural`.
3. الوضع التجريبي يعمل دون مفاتيح عبر سيناريو محلي وTTS وخلفيات فنية، ولا يتصل بمزود النصوص أو الفيديو. للاستخدام الكامل اختر Groq أو Gemini وأضف المفتاح من الإعدادات. أضف مفتاح Pixabay اختيارياً لجلب لقطات فعلية؛ بدونه يستخدم التطبيق خلفيات محلية.
4. تابع المراحل ثم عاين MP4 ونزّله. يحفظ الأرشيف وبياناته داخل `data/outputs/` على جهازك.

## اختيار نموذج Gemini والرجوع التلقائي

تستخدم خدمة Gemini واجهة `ListModels` الرسمية لقراءة الصفحات المتاحة، وتتحقق من `supportedGenerationMethods`، ثم تختار من قائمة نماذج التوليد النصي ذات الحصة المجانية المعروفة. وفق كتالوج Google الرسمي وقت هذا التحديث (19 نوفمبر 2026)، النموذج المفضل هو `gemini-4-hydrogen`، ثم تتوفر بدائل مثل `gemini-3.8-flash` و`gemini-3.6-flash` و`gemini-3.5-flash-lite`. يحاول التطبيق البديل التالي إذا أعاد النموذج خطأ أو 404. لا يستخدم نماذج Pro المدفوعة. يظل توفر النموذج والحصة الفعلية تابعاً لمشروع Google ومفتاح المستخدم؛ لذلك قد يفشل الاتصال عند تجاوز الحصة أو بسبب إعداد المفتاح.

تُظهر وثائق Google أن `gemini-2.5-flash` متقادم، ووصوله الحالي محدود لبعض المستخدمين؛ لذلك لا يُستخدم كخيار افتراضي. لا يظهر هذا النموذج ضمن المحاولة الاحتياطية إلا إذا أدرجته `ListModels` المتاحة للمفتاح. المصادر الرسمية: [كتالوج Gemini](https://aistudio.google.com/docs/models)، [أسعار Gemini API والحصة المجانية](https://aistudio.google.com/docs/pricing)، [ListModels](https://aistudio.google.com/api-reference/models/list-models)، و[GenerateContent](https://aistudio.google.com/api-reference/generate-content/generate-content).

## Pixabay Videos API

يستخدم جالب الفيديو نقطة النهاية الرسمية `https://pixabay.com/api/videos/` مع `key` و`q`. تُرسل عبارة البحث بحد أقصى 100 حرف، ثم تُقرأ النتائج من `hits[].videos`. يختار التطبيق ملفاً مناسباً لاتجاه الفيديو من الأبعاد المتاحة، ويرفض الملفات التي تتجاوز 90 ميغابايت. كلمات البحث المرئي تُنقّى إلى الإنجليزية حتى عند اختيار العربية. راجع [توثيق Pixabay Developer API](https://pixabay.com/api/docs/) و[صفحة Pixabay الرسمية عن API](https://pixabay.com/service/about/api/) لمعلومات التسجيل وشروط الاستخدام الحالية.

## المفاتيح والخصوصية

مفاتيح Groq وGemini وPixabay تُخزَّن في `localStorage` لهذا المتصفح فقط، ولا تُحفظ في ملفات الخادم أو سجلاته؛ يرسلها المتصفح إلى الخدمة الخلفية عند بدء المهمة. مفاتيح Pixabay وGemini تُستخدم في طلبات HTTPS ولا تُضمَّن في بيانات الفيديو أو ZIP. استخدم نسخة محلية على جهازك الشخصي، ولا تدخل مفاتيحاً شخصية في معاينة عامة أو متصفح مشترك. من الأفضل مسح المفاتيح عند الانتهاء على جهاز مشترك. احتفظ بمفاتيحك في مزودها ولا تضعها داخل ملفات المصدر أو ZIP.

تعتمد الخدمات الخارجية على سياساتها وحصصها ومفاتيحها؛ لا يعني وصف «مجاني» أن المزود يضمن حصة غير محدودة. لائحة النماذج وGroq وPixabay قابلة للتغيير؛ إذا غيّر المزود نقطة API أو قواعد الاستخدام، راجع توثيقه الحالي.

## الدقة والمخرجات

يُنشئ التطبيق ملف ASS عربي RTL؛ يستخدم FFmpeg/libass تشكيل النص واتجاهه، ويحدد faster-whisper أزمنة بداية ونهاية كل مشهد باللغة المناسبة (`en` أو `ar`). الترجمة تجميع على مستوى المشهد، لا تفريغاً كلمةً بكلمة؛ يُستحسن مراجعة النص والتوقيت قبل النشر. يُنشأ مسار موسيقى خلفية توليدي خافت محلياً، وتستطيع إيقافه بتغيير خيار `background_music` في طلب API.

النسخة التجريبية تستخدم خلفيات تصميمية ثابتة محلياً كي تعمل دون مفتاح Pixabay، وليست لقطات أرشيفية حقيقية. يتطلب جلب اللقطات الفعلية مفتاح Pixabay صالحاً. المخرجات التجريبية لا تُعد تحققاً من دقة الحقائق أو من شروط مزود المحتوى الخارجي.

## بنية المشروع

`app/main.py` واجهة الخدمة والمهام والتنزيل؛ `app/pipeline.py` خط الإنتاج؛ `app/providers.py` موصلات النص وGemini model fallback وPixabay؛ `app/media.py` الصوت والمزامنة والتركيب؛ `app/templates` و`app/static` الواجهة. تُنشأ ملفات الفيديو في `data/outputs/` ومجلدات العمل المؤقتة في `data/work/`.

## التشغيل اليدوي

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
HOST=127.0.0.1 PORT=3000 python -m app.main
```

على Windows فعّل البيئة عبر `.venv\\Scripts\\activate` ثم استخدم `python -m app.main`. المتطلبات الأساسية تشمل Python 3.11+ وFFmpeg حديثاً مع libass. لتخفيض استهلاك الذاكرة غيّر `whisper_model` في جسم طلب `/api/generate` إلى `tiny` (الخيار الافتراضي)، أو اختبر `base` للحصول على تفريغ أفضل مقابل وقت أطول.

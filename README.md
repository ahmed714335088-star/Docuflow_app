# DocuFlow — استوديو إنتاج الفيديو الوثائقي

لوحة عربية RTL مبنية بـFastAPI لإنتاج فيديوهات وثائقية عربية أو إنجليزية، أفقية 16:9 أو عمودية 9:16. يختار المستخدم مدة 1 أو 3 أو 5 أو 10 دقائق. يحدد كاتب السيناريو لكل مشهد `ai_image` أو `stock_video`: صور Gemini الأصلية تُستخدم للأحداث التاريخية والمفاهيم والسرد الدرامي بعد موافقة المستخدم، بينما فيديوهات Pixabay لا تُقبل إلا إذا تطابقت وسومها مع الموضوع والمشهد. إن غاب مقطع `stock_video` يطلب التطبيق صورة Gemini كبديل؛ وإذا تعذر أصل مطابق/مصرح به يتوقف الإنتاج بدلاً من استخدام لقطات عامة.

يوزّع التطبيق مشاهد الجدول على المدة المختارة: 19/58/97/194 مشهداً لـ1/3/5/10 دقائق، بفاصل تقريبي 3.09–3.15 ثانية شاملاً 0.5 ثانية صمت صوتي. يُمدد الصوت القصير بصمت إلى مساحة الكلام المخصصة، ويوقف المشهد إذا تجاوزت الجملة المساحة المتاحة؛ لا يتغير معدل النطق تلقائياً. انتقال `crossfade` النهائي 0.22 ثانية محسوب في الجدول. يطبع التطبيق كل فيديو مصدر عبر `-map 0:v:0 -an -sn -dn` مع حذف metadata وtimecode، حتى لا تتسرب مسارات `tmcd` إلى ملفات المشاهد.

## التشغيل السريع

**Windows:** ثبّت Python 3.11 أو أحدث وFFmpeg مع دعم `subtitles/libass`، وأضف `ffmpeg` إلى PATH. شغّل `start.bat`؛ ينشئ بيئة Python ويثبت المتطلبات عند أول تشغيل ثم يفتح `http://127.0.0.1:3000`.

**Linux:** ثبّت Python 3.11 أو أحدث وFFmpeg وlibass والخط العربي، مثلاً في Ubuntu/Debian: `sudo apt-get install ffmpeg libass9 fonts-noto-core python3-venv`. امنح `start.sh` صلاحية التنفيذ عند الحاجة (`chmod +x start.sh`) ثم شغّله.

تحتاج edge-tts إلى الإنترنت؛ أول تشغيل لـfaster-whisper ينزّل نموذج التفريغ. المعالجة الطويلة تتطلب وقت CPU ومساحة أكبر. سيناريو الجيزة التجريبي محدود؛ ولإنتاج فيديو فعلي يلزم توافر المفاتيح والموافقة التي تتطلبها المشاهد والصور ومصدر مرئي مطابق. لا توجد مفاتيح لمزودات الذكاء الاصطناعي مضمّنة.

## الاستخدام ومحدد المدة

1. أدخل موضوعاً واحداً أو قائمة موضوعات (موضوع لكل سطر، حتى 8 موضوعات في الدفعة)، وحدد اللغة والصوت والسرعة والنسبة والمدة. السرعة الافتراضية `-12%` والمنزلق من `-25%` إلى `+10%`؛ نبرة الصوت `-3Hz`. لا يعيد التطبيق توليد الجمل بسرعة أعلى تلقائياً، ويوقف المشهد إذا لم يتسع الكلام للصوت والوقفة.
2. يطلب السيناريو خطافاً في البداية، وتصاعداً وخاتمة. المشهد قصير واستعلام المرئيات الإنجليزي محدد، مثل `cargo ship storm Atlantic night` أو `vintage airplane flying clouds archival` أو `compass navigation map closeup`، لا كلمات عامة مثل `fog` أو `ocean`. يُطلب من النموذج تفادي اختلاق أرقام ومصادر وتمييز الحقيقة المنقولة عن الفرضية. عند العربية يُكتب السرد بالعربية الفصحى وتُختار أصوات مثل `ar-EG-ShakirNeural` أو `ar-SA-HamedNeural`.
3. **توجيه المرئيات:** لمشهد `ai_image` يستخدم التطبيق نموذج صورة Gemini نشطاً يعيده `models.list` و`generateContent` مع `responseModalities:["IMAGE"]`. يجب تفعيل مربع الموافقة وإدخال مفتاح Gemini لكل تشغيل؛ وعند HTTP 429 فقط يحاول مقطع Pixabay يطابق الوسوم. لمشهد `stock_video` يقبل التطبيق فيديو Pixabay مطابق الوسوم فقط، وإلا يطلب صورة Gemini كبديل. لا تُقبل صورة Pixabay الثابتة بديلاً عن فيديو مفقود. الصور المولدة تُطبّع إلى HD ويضاف إليها تحريك Ken Burns. لا يُحلّل النظام بكسلات Pixabay، لذلك لا يُدّعى ضمان بصري يتجاوز بيانات الوسوم.
4. **النص:** تتوفر Groq وGemini وClaude والوضع التجريبي، إضافة إلى خيار Pollinations. يكتشف Claude أحدث نموذج Sonnet ظاهر لحساب Anthropic عبر `/v1/models` ويرسل السيناريو عبر Messages API؛ قد تترتب تكلفة أو تُستهلك حصة، لذا راجع الأسعار وحد الإنفاق. وضع التجربة محدود بالسيناريو الموثق لأهرامات الجيزة ولا يمثل كتابة مخصصة من نموذج.
5. **Pixabay وPollinations:** يحتفظ التطبيق بمعرّفات فيديوهات Pixabay لمنع تكرارها. تُرفض نتائج الفيديو ذات الوسوم غير المطابقة ولا تُملأ الفجوات بلقطات عامة. Pollinations خيار احتياطي إضافي اختياري يحتاج مفتاحاً وموافقة منفصلة، وقد يستهلك رصيد Pollen.
7. تابع التقدم، ثم عاين MP4 ونزّله إن اكتمل التوليد. تُحفظ المخرجات في `data/outputs/` على الجهاز.

## مطابقة المرئيات وإيقاع الفيديو

لكل مشهد مرساة موضوع ثابتة واستعلام إنجليزي مخصص. يُرفض فيديو Pixabay ما لم تتوافق وسومه مع المرساة ومصطلحات المشهد، وتُمنع إعادة معرّف الفيديو في الفيلم نفسه. صورة Gemini تُستخدم للمشهد الذي اختير له `ai_image`، أو بديلة لفيديو stock غير متوفر. عند حد Gemini (HTTP 429) يجرب النظام فيديو Pixabay بعلامات متطابقة بدلاً من تكرار الطلب؛ لا تُقبل صورة Pixabay الثابتة كبديل. المطابقة المرئية تعتمد على metadata ولا تحلل البكسلات؛ افحص الناتج قبل النشر.

يطبق FFmpeg حركة كاميرا 24fps (zoom-in / zoom-out وتحريك أفقي أو رأسي) على الصور. يركب MoviePy انتقالات `crossfade` بين المشاهد، وتظل صورة Gemini أو فيديو Pixabay مرتبطة بالمشهد القصير. لا يمكن ضمان وجود لقطة مخزون مناسبة لكل استعلام.

`8K-style` إن ظهر في وصف صورة مولدة يعني أسلوب/تفاصيل، لا إخراجاً فعلياً بدقة 8K. دقة الخرج HD: `1280×720` أو `720×1280`.

## الصوت والترجمة

يولد edge-tts مقطعاً مستقلاً لكل جملة بسرعة يحددها المستخدم (من `-25%` إلى `+10%`، افتراضياً `-12%`) وطبقة صوت `-3Hz`. لا يعاد توليد الصوت بسرعة أعلى تلقائياً. تُضاف 0.5 ثانية صمت فعلي بين المقاطع دون تغيير السرعة؛ إذا تجاوزت الجملة الفاصل المسموح، يتوقف الإنتاج برسالة تطلب نصاً أقصر أو سرعة أخرى.

يستخرج faster-whisper توقيت الكلمات، ثم تقسم الترجمة العربية إلى شاشات من 3–5 كلمات بحروف ASS مشكلة RTL. في السرد العربي يساعد التفريغ العربي على محاذاة الجمل مباشرة. أما عندما يكون الراوي إنجليزياً والترجمة عربية، فتوزع مجموعات الكلمات العربية على الطابع الزمني للكلمات المنطوقة بنسبة الكلمات؛ هذه محاذاة مقطعية تقريبية وليست ترجمة كلمة بكلمة أو ضماناً لتطابق دلالي تام. راجع النص والتزامن قبل النشر.

يولّد التطبيق موسيقى وثائقية محيطية محلياً ويخلطها تحت صوت الراوي، ثم يطبع المزيج بتمريرين عبر FFmpeg إلى هدف `−14 LUFS` و`−1.0 dBTP` مع limiter. القياس النهائي قد يتأثر بترميز AAC ومحتوى الصوت؛ استمع للملف النهائي قبل النشر.

## المفاتيح والخصوصية والتكلفة

مفاتيح Groq وGemini وClaude وPixabay وPollinations تحفظ في `localStorage` لهذا المتصفح وترسل إلى الخلفية عند بدء التوليد، ولا تُكتب في ZIP. Claude وGemini قد يستهلكان رصيداً أو حصة بحسب الحساب؛ راجع الأسعار والحدود قبل التشغيل. Pollinations يتطلب مفتاحاً وموافقة منفصلة وقد يستهلك Pollen. لا يتضمن ZIP مفاتيح API أو ملفات فيديو مولدة.

## التشغيل اليدوي

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
HOST=127.0.0.1 PORT=3000 python -m app.main
```

على Windows فعّل `.venv\\Scripts\\activate` ثم شغّل `python -m app.main`. يتطلب التشغيل Python 3.11+ وFFmpeg حديثاً بدعم libass. يستخدم التطبيق افتراضياً نموذج faster-whisper `tiny` لتقليل الذاكرة والوقت.

## تشغيل محلي عبر Docker

ثبّت Docker Desktop أو Docker Engine مع Docker Compose، ثم من مجلد المشروع شغّل:

```bash
# Linux/macOS: مرّر UID/GID الحاليين كي تبقى الملفات المنشأة قابلة للكتابة من حسابك
APP_UID="$(id -u)" APP_GID="$(id -g)" docker-compose up -d --build
```

على Windows PowerShell أو Command Prompt (القيم الافتراضية 1000)، استخدم `docker-compose up -d --build`. يقبل Docker Compose v2 أيضاً الصيغة الحديثة `docker compose up -d --build`. افتح `http://localhost:3000`. عند احتلال المنفذ، غيّر منفذ المضيف مثلاً إلى `DOCUFLOW_PORT=3001` قبل التشغيل.

يحفظ الربط `./data:/app/data` الفيديوهات في `./data/outputs/` وملفات العمل في `./data/work/` على جهازك. يحفظ volume المسمى `docuflow_whisper_cache` نموذج faster-whisper بعد تنزيله لتجنب إعادة التنزيل. التطبيق يعمل بحساب غير root داخل الحاوية؛ يهيئ entrypoint مجلدات البيانات ثم يخفض الصلاحيات إلى UID/GID المحددين. لمزامنة الخدمة: `docker-compose logs -f`؛ للإيقاف: `docker-compose down` (لا يحذف البيانات). لا تستخدم `docker-compose down -v` إلا إذا أردت حذف كاش Whisper أيضاً.

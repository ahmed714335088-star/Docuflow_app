# DocuFlow — لوحة إنتاج الفيديو الوثائقي

لوحة عربية RTL مبنية بـFastAPI لإنتاج فيديوهات وثائقية قصيرة وShorts بإيقاع سريع. يطلب المحرك 12 مشهداً سردياً قصيرة، ويستهدف 3–5 ثوانٍ للمشهد، بصوت عربي أو إنجليزي وترجمة عربية RTL. لكل مشهد يبحث أولاً عن فيديو Pixabay، ثم عن صورة Pollinations عند تفعيلها صراحةً، ثم صورة Pixabay ثابتة تُحرَّك بكاميرا Ken Burns، وأخيراً خلفية محلية حركية بلا مفتاح. تُركّب المشاهد والصوت والترجمة والموسيقى في MP4.

## التشغيل السريع

**Windows:** ثبّت Python 3.11 أو أحدث وFFmpeg مع دعم مرشح `subtitles/libass` وأضف `ffmpeg` إلى PATH. انقر نقراً مزدوجاً على `start.bat`؛ ينشئ بيئة Python ويثبت المتطلبات عند أول تشغيل ثم يفتح `http://127.0.0.1:3000`.

**Linux:** ثبّت Python 3.11 أو أحدث وFFmpeg وlibass والخط العربي، على سبيل المثال في Ubuntu/Debian: `sudo apt-get install ffmpeg libass9 fonts-noto-core python3-venv`. امنح `start.sh` صلاحية التشغيل عند الحاجة (`chmod +x start.sh`) ثم شغّله. تُفتح اللوحة على `http://127.0.0.1:3000`.

يلزم الإنترنت لـedge-tts وPixabay ومزودي الكتابة؛ أول تشغيل لـfaster-whisper ينزّل نموذج التفريغ. يتطلب التوليد موارد CPU ومساحة للقطات، وقد تستغرق معالجة 12 مشهداً أكثر من دقيقة.

## الاستخدام

1. أدخل موضوعاً أو قائمة موضوعات (موضوع لكل سطر، حتى 8 موضوعات في الدفعة). يطلب محرك الكتابة 12 مشهداً قصيرة، بخطاف وتصاعد أدلة وانعطاف وكشف وخاتمة، وبسرد يتراوح عادةً بين 6 و12 كلمة للمشهد. يتكيف Edge TTS مع المشهد الذي يتجاوز خمس ثوانٍ بإعادة توليده بإيقاع أسرع. المدة النهائية تتبع سرعة الراوي.
2. اختر YouTube 16:9 أو Shorts 9:16، ثم لغة الفيديو والصوت المناسب. عند العربية يُكتب السرد بالعربية، ويُستخدم صوت مثل `ar-EG-ShakirNeural` أو `ar-SA-HamedNeural` وتُعرض الجملة العربية نفسها كترجمة. تبقى كلمات البحث للمرئيات دائماً بالإنجليزية.
3. **Gemini:** أضف Google API Key؛ يقرأ التطبيق `models.list` لحسابك ويتحقق من `supportedGenerationMethods=generateContent`، ثم يرتّب Flash/Lite المتاحة قبل النماذج الأخرى ويتجاوز المعرف الذي يعيد 404/عدم التوفر. لا يعتمد على اسم نموذج ثابت. استقرار النموذج والحصة يعتمدان على إعدادات وحصة مفتاحك.
4. اختر Groq أو زر Pollinations النصي الاحتياطي من المحرك. الوضع التجريبي لا يتصل بخدمة نص خارجية ويستخدم سيناريو من 12 مشهداً. تحتاج Groq وGemini إلى مفاتيح مزودهما. Pollinations API الحالي **ليس keyless**: التوليد يحتاج API Key وقد يستهلك Pollen. لإرساله، أضف المفتاح في الإعدادات وفعّل مربع الموافقة الصريح لكل عملية؛ خُصصت النماذج المفضلة لاختيار الأقل سعراً في الكتالوج المتاح، لكن السعر/الرصيد قد يتغيران.
5. أضف Pixabay API Key لجلب فيديوهات حقيقية. إذا لم يوجد مقطع مناسب، يُحاول التطبيق إنشاء صورة Pollinations فقط مع المفتاح والموافقة؛ وإلا يبحث عن صورة Pixabay ويضيف لها حركة كاميرا، أو يستخدم خلفية محلية متحركة. لا يحتاج المسار المحلي إلى Pollinations.
6. تابع المراحل، ثم عاين MP4 ونزّله. يحفظ الأرشيف والبيانات في `data/outputs/` على الجهاز.

## Gemini: اكتشاف النموذج تلقائياً

يطلب التطبيق `GET https://generativelanguage.googleapis.com/v1beta/models?key=...` مع صفحات `pageToken`، ولا يقبل إلا المعرفات التي تسجل Google لها `generateContent`. يفضل نماذج Flash/Lite النشطة ذات أسماء المعرفات التي أعادتها قائمتك؛ وإذا رفض أحدها الطلب أو أعاد 404/429/5xx، ينتقل إلى المعرف النشط التالي. لا توجد أسماء موديلات قديمة مخفية كخطة افتراضية. لا يمكن لقائمة `models.list` وحدها ضمان حصة مجانية؛ الحصة ونوع المشروع وحدود النموذج يقررها حساب Google، لذلك يشرح التطبيق 401/403 بدلاً من تدوير معرفات غير موجودة. مصادر Google الرسمية: [ListModels](https://aistudio.google.com/api-reference/models/list-models)، [GenerateContent](https://aistudio.google.com/api-reference/generate-content/generate-content)، [كتالوج النماذج](https://aistudio.google.com/docs/models)، و[الأسعار والحصص](https://aistudio.google.com/docs/pricing).

## Pollinations: الإفصاح عن المفتاح والرصيد

تغيّر Pollinations API؛ توثيقها الحالي يوجّه التوليد عبر `https://gen.pollinations.ai` باستخدام Bearer API Key من فئة `sk_`، وتعرض كتالوجات `/text/models` و`/image/models` حقول الأسعار ونقاط النهاية المدعومة. قد لا يتطلب بعض النموذج حداً أدنى مدفوعاً (`paid_only=false`) لكنه لا يعني أن طلب الصورة بلا تكلفة؛ الكتالوج الحالي يعبّر عن سعر الصورة بعملة Pollen. لذلك لا يرسل DocuFlow أي توليد Pollinations ما لم يوجد المفتاح ويُفعّل المستخدم خانة الموافقة، ويختار التطبيق النموذج الصحي الأقل سعراً في الكتالوج. يمكن أن يصل الحد إلى 12 صورة لكل فيديو (حتى 96 صورة في دفعة من 8 موضوعات)، وتمنع الموافقة غير المفعّلة أي نداء لتوليد الصور. عند الرصيد غير الكافي يوقف التطبيق محاولات الصور اللاحقة في الدفعة ويستخدم Pixabay/الحركة المحلية. مصادر المزود: [التوثيق الرسمي](https://gen.pollinations.ai/docs) و[مرجع API الرسمي](https://github.com/pollinations/pollinations/blob/main/APIDOCS.md).

## المشاهد والحركة المرئية

يعيد Groq/Gemini/Pollinations JSON يتضمن `narration` و`translation_ar` و`visual_keywords` الإنجليزية و`image_prompt` الإنجليزي. يُقصَّر الرد إلى 12 مشهداً، ولا يقبل التطبيق أقل من 8. يتكيف الصوت الطويل عبر edge-tts إلى إيقاع أسرع قبل التوقيت. يقص Pixabay الفيديو الحقيقي إلى مقاس العرض؛ وتطبق مرشحات FFmpeg على الفيديو والصور والخلفيات بتحريك 24fps يتناوب فيه zoom-in وzoom-out والتحريك الجانبي/العمودي، بحيث لا تبقى الصور ثابتة. المسار المحلي يرسم خلفيات وثائقية مولدة محلياً ثم يضيف حركة الكاميرا.

عبارة `8K-style` في وصف الصورة تعني مستوى التفاصيل والجو السينمائي لا دقة إخراج فعلية. ملفات التطبيق تخرج HD بمقاس 1280×720 أو 720×1280؛ رفع الدقة إلى 8K غير جزء من هذا المحرك.

## الصوت والترجمة

يستخدم faster-whisper لغة التفريغ المناسبة (`en` أو `ar`) لتحديد نطاق كلام كل مشهد؛ وتظهر ترجمة المشهد العربية في هذا النطاق، وتُحرق بصيغة ASS عبر FFmpeg/libass بتشكيل RTL. التوقيت متزامن على مستوى كل مقطع سردي، وليس تفريغاً كلمةً بكلمة؛ يُستحسن تدقيق النص قبل النشر. ينشئ التطبيق موسيقى محيطية محلية خافتة ويخلطها تحت الراوي.

## المفاتيح والخصوصية

مفاتيح Groq وGemini وPixabay وPollinations تُخزَّن في `localStorage` لهذا المتصفح فقط، ولا تُحفظ على الخادم في الملفات أو سجلات التطبيق؛ يرسلها المتصفح مع طلب الإنتاج إلى الخلفية. استخدم النسخة المحلية على جهازك الشخصي، ولا تدخل مفاتيحاً في متصفح مشترك. افحص الأسعار/الحدود لدى المزود قبل الموافقة على Pollinations؛ احذف المفاتيح بعد الاستخدام على الأجهزة المشتركة. لا يتضمن ZIP أي مفاتيح أو فيديوهات مولّدة.

## التشغيل اليدوي

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
HOST=127.0.0.1 PORT=3000 python -m app.main
```

على Windows فعّل `.venv\\Scripts\\activate` ثم استخدم `python -m app.main`. المتطلبات الأساسية تشمل Python 3.11+ وFFmpeg حديثاً مع libass. الخيار الافتراضي لـfaster-whisper هو `tiny` لتقليل الذاكرة ووقت المعالجة.
